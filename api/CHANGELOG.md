# Журнал изменений API сводного плана сетей

Формат записи: версия — дата, что изменилось. Несовместимые изменения (удаление или переименование маршрута или поля, новое обязательное поле, смена смысла) помечаются словом «НЕСОВМЕСТИМО». Изменения служебных маршрутов показа отдельно не отмечаются (см. [соглашения](02_соглашения.md)).

## 1.0 — 2026-11-09, первая версия

Что охвачено:

- **Доступ по личному ключу сотрудника компании** (`Authorization: Bearer`), режимы «Чтение» (включая три чтения показа методом `POST`) и «Полный — по роли», проекты ключа из одной компании, срок 30, 90 или 365 дней, не больше 10 действующих ключей у человека, отзыв. Маршрут `GET /api/platform/network-federation/me` — владелец, режим, срок и проекты ключа.
- **Все маршруты сводного плана, которыми пользуется интерфейс:** сводный план проекта и разделы, настройки раздела на весь проект (подоснова, цвет, показ по умолчанию) и порядок прорисовки разделов и чертежей в разделе, файлы и версии чертежей, загрузка чертежей кусками (сессия, `Content-Range`, завершение, повтор, отмена), состояние импорта CAD, подготовка версий к показу, модели IFC, проверка версий (принять, вернуть с причиной, сделать актуальной), состав и размещения, снимки, шрифты, сравнения, сводки изменений, обсуждения с метками и вложениями, виды и конфигурации показа, участники и роли, приглашения, ссылки просмотра, архив оригиналов. Справочник описывает 126 операций, доступных ключу.
- **Закрыто для ключа:** служебная правка данных, администрирование пользователей платформы, прямой импорт CAD мимо загрузки сводного плана (из импорта открыто только чтение состояния), подложки PDF.
- **Соглашения:** коды ошибок слоя ключа (`AGENT_TOKEN_INVALID`, `AGENT_GRANT_DENIED`, `API_KEY_WITH_SESSION`, `API_KEY_EMPLOYEES_ONLY`, `API_KEY_LIMIT`, `API_KEY_PROJECTS_ONE_COMPANY`, `RATE_LIMIT_AGENT_READ`, `RATE_LIMIT_AGENT_WRITE`), версия документа `expectedVersion` (428 и 409), лимиты 600 чтений и 120 записей в минуту с `Retry-After`.
- **Документация:** справочник и описание OpenAPI 3.1, создаваемые из каталога маршрутов, сценарии, примеры на Python.
