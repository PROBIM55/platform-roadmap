# План развития сводного плана

Обновлено 20.10.2026.

**[Полный план — текущая очередь, пожелания и выполненные этапы](FULL-PLAN.md)** · [История исследований и прежних срезов](HISTORY.md)

Блок пожеланий содержит девять постоянных записей; [полный состав, текущая очередь и статусы — в первом разделе полного плана](FULL-PLAN.md#wishes).
Очередь единая: № показывает порядок выполнения, P0/P1/P2 — приоритет. WISH-001 и WISH-002 остаются №001/002; далее главный P0 охватывает точность текущего CAD-просмотра и затем скорость/потоковую загрузку полной сцены. См. [главный фокус](FULL-PLAN.md#cad-viewer-p0-2026-10-20). Задачи связаны с разделами [fidelity](FULL-PLAN.md#fidelity), [viewer](FULL-PLAN.md#viewer) и [storage](FULL-PLAN.md#storage). Выполненные и исторические этапы номера не получают. ID остаётся постоянным идентификатором записи, а не её местом в очереди.

Локальный контроль: пакетное разрешение ресурсов сократило число запросов с 235 до 15; готовность контрольной сцены — с 48,3 до 19,1–20,6 с. Это три наблюдения; проверка плавности и точности всего состава продолжается.
Отдельный прежний локальный замер объединения уведомлений прогресса до миграции V2: обычная готовность сцены ограниченного одинакового состава из 235 источников составила 23,2 с до изменения и 11,7 / 11,1 с после. В момент замера фоновая детализация ещё выполнялась. Эти значения не описывают текущее открытие состава 235 на V2, не являются метрикой FPS и не характеризуют холодное открытие.
Общий обработчик текста и геометрии был включён и проверен повторной обработкой одного исходного чертежа на локальном контрольном стенде. В ходе этой проверки все 235 ранее загруженных чертежей получили пакеты актуальной на тот момент схемы и открылись в контрольной сцене без ошибок. Проверки целостности и структуры точной геометрии пройдены; исходники и прежние варианты сохранены. Для дополнительного проблемного чертежа весь пакет совпал с обычным эталонным экспортом SDK.
Полная визуальная сверка, сопоставление изменений геометрии и проверка плавности продолжаются. Проверено на локальном контрольном стенде; публикация этих изменений в текущей сборке отдельно не подтверждена.
