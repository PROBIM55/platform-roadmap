# План развития сводного плана

Обновлено 20.10.2026.

**[Полный план — текущая очередь, пожелания и выполненные этапы](FULL-PLAN.md)** · [История исследований и прежних срезов](HISTORY.md)

Очередь единая: № показывает порядок выполнения, P0/P1/P2 — приоритет. Выполненные и исторические этапы номера не получают. ID остаётся постоянным идентификатором записи, а не её местом в очереди.

Локальный контроль: пакетное разрешение ресурсов сократило число запросов с 235 до 15; готовность контрольной сцены — с 48,3 до 19,1–20,6 с. Это три наблюдения; проверка плавности и точности всего состава продолжается.

Новый локальный этап: сокращены лишние обновления прогресса. В отдельном сравнении одинаковых 235 источников обычная готовность сцены составила 23,2 с до изменения и 11,7 / 11,1 с после. Фоновая детализация в этот момент ещё выполнялась; это не метрика FPS или холодного открытия. Общий обработчик текста и геометрии включён локально и проверен повторной обработкой одного исходного чертежа. Обновление остальных импортов и проверка плавности продолжаются.
