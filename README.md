# План развития сводного плана

Обновлено 26.11.2026.

**[Полный план — задачи, единая очередь и выполненные этапы](FULL-PLAN.md)** · [История исследований и прежних срезов](HISTORY.md)

[Обучение — №061](FULL-PLAN.md#wish-019): короткий обзор для руководителей готов и принят. Экран принятия версии уже реализован, проверен локально и выпущен. Остаются подробное руководство для координаторов и полный сценарий первого знакомства с модулем. [По тяжёлым чертежам](FULL-PLAN.md#src01-445) получен положительный пользовательский отзыв на показанном наборе; полная визуальная матрица и плавность остаются открытыми. [Изменение структуры](FULL-PLAN.md#wish-034) допускается отложить, если оно мешает показу уже работающих функций.

Ближайшие новые требования:

- [№008 — скрытие штриховок и заливок](FULL-PLAN.md#wish-033): обратимый переключатель для читаемости плана, без изменения исходного DWG.
- [№009 — дерево состава](FULL-PLAN.md#wish-034): разделы, подпапки и файлы с ручным выбором места загрузки. Точную структуру ещё нужно согласовать.
- [№010 — нормализация слоёв](FULL-PLAN.md#src01-420): дополнить существующие правила разделением конструктивных элементов и аннотаций. Готовые этапы профиля сохраняются.
- [№011–013 — переносимый CAD-комплект](FULL-PLAN.md#wish-021): общий ZIP раздела и всего состава, многоуровневые сборочные файлы и относительные внешние ссылки. Базовый ZIP уже есть; иерархическая сборка ещё предстоит.
- [№014 — таблица состава в CAD](FULL-PLAN.md#wish-035): нативная таблица из согласованного реестра с предпросмотром обновлений и сохранением прежних выпусков.

Первые семь мест сохранены. [Ошибки загрузки DWG — №005](FULL-PLAN.md#wish-029), [удаление отдельного файла — №006](FULL-PLAN.md#wish-030) и [переименование — №007](FULL-PLAN.md#wish-032) имеют локально реализованные и проверенные этапы; оставшиеся сценарии и подтверждение рабочего выпуска указаны в самих задачах. Новые требования выше не объявлены реализованными.

[Программный доступ](FULL-PLAN.md#wish-024): 26.11 обновлены [руководство и примеры API до версии 1.2.1](api/README.md), а форма создания ключа объясняет обязательное название программы. Выпуск ключа и работа по постоянным идентификаторам после переименования проекта, раздела и файла проверены локально и на рабочем сайте. [Трассы и проверки сетей](FULL-PLAN.md#wish-028), [точность CAD-просмотра](FULL-PLAN.md#src01-445), [обсуждения](FULL-PLAN.md#collaboration) и все прежние направления сохранены в полном плане. [Автораспределение входящего архива](FULL-PLAN.md#wish-026) остаётся отложенным.

№ обозначает относительный порядок, P0/P1/P2 — критичность, постоянный ID — саму задачу. Завершённые и исторические этапы не занимают место в очереди. Реализация в коде, локальная проверка и выпуск различаются; номер не обещает срок.
